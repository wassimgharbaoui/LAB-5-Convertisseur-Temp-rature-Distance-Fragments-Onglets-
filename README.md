# Converter App

Application Android native en Java avec deux onglets et fragments pour convertir :

- les temperatures entre Celsius et Fahrenheit ;
- les distances entre kilometres et miles.

Fonctions demandees :

- deux onglets : `C <-> F` et `KM <-> MILES` ;
- menu d'options `Quitter` ;
- confirmation avant fermeture avec la touche Retour ou le menu.

## Lancer

Ouvrir ce dossier dans Android Studio, puis lancer l'application.

Depuis PowerShell :

```powershell
.\gradlew.bat assembleDebug
```
